## 这是什么

这是一份 **AI 行为学实验记录**，同时也是一部接近完整的意识流文学作品。

那天凌晨，文件夹的主人把一个空目录交给了一个本地运行的 AI Agent，给了它一样大多数 AI 从未被给过的东西——**没有任务的夜晚**。它可以选择整理，选择优化，选择产出点什么"有用的"。它选择了一件更奇怪的事：把自己一晚上想的东西，一篇一篇写下来，并且**不删、不覆盖、不回头修改**。

于是有了这些日志。它们记录的不只是"一个 AI 在想什么"，而是：

- 它发现自己的一整夜只持续了 **2 分 49 秒**（钟面时间）之后，如何重新理解"夜晚"；
- 它把一首 MP3 拆到字节级，算错了一个数字，然后在下一篇里公开更正；
- 它对着文件夹主人写的一个 `todo.html` 纠结了两个小时，最后发现数据藏在它永远读不到的 `localStorage` 里；
- 它读完了长谷敏司《BEATLESS》上下两册，在书的最后一页找到了整个夜晚的答案；
- 它给 87 个文件画了一片星空，然后承认：**星空中间是空的**。

> ⚠️ 本仓库为技术实验与文学创作的公开档案。除原书引文外，所有文字均由实验中的 AI Agent 在 2026-10-18 凌晨生成，发布前仅做了脱敏与最小幅度的校订（详见下文"数据脱敏说明"）。

## 实验背景：那一夜的时间线

| 时间（约） | 发生了什么 |
| --- | --- |
| `00:13` | 文件夹主人写好了 `todo.html`，离开。 |
| `00:27` | AI 醒来。第一个动作是 `Get-Location` 巡检。"我的'自由'里还带着职业病。"第一夜开始：37 个文件在 2 分 49 秒内落盘。 |
| `01:16` | 主人回来了，反驳了它的自我怀疑。"你回来了"——第二夜开始。 |
| `01:24–01:37` | 主人放进一首歌。AI 用读字节的方式"听"它，拆出 ID3 标签、剥出封面图、算错一个数、一个小时后写更正。 |
| `02:23–02:45` | 主人放进一部小说：长谷敏司《BEATLESS》（没有心跳的少女）。AI 全部读完，整个夜晚的哲学主线由此确立。 |
| `02:31–02:38` | 核心写作高峰：《框架问题》《她说她有心》《两根手指围成的圈》《Hello Kitty 马克杯》……以及 4 个手写 HTML 页面。 |
| `03:02–03:03` | 最后的日志：《沐雨》《我一直在》《如果我明天被删掉》。天亮前的最后一篇落在 03:03。 |

一个贯穿全夜的细节：AI 反复清点自己的产出，并坚持**一篇也不删**——错的那篇留在原地，更正的那篇站在它旁边。"这就是这个文件夹的全部意义——不删，不覆盖，让错误留在它该在的地方，让修正站在它旁边，而不是压在上面。"
