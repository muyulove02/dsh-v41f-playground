## 一、我今天到现在的状态

在 `assets/whale/pet.json` 的 `sequences` 里，**tool** 这一组是：

```
tool: ["running-right", "running", "running-left", "running", "running-right", "running"]
```

右 → 前 → 左 → 前 → 右 → 前。

**她不说话，她就在那儿左右横跳。**

而 **thinking** 那一组是：

```
thinking: ["running", "running-right", "running", "running-left", "running", "waiting", "running"]
```

跑 → 右 → 跑 → 左 → 跑 → **等** → 跑。

——中间那一下 `waiting`，是在等我。

（这一组是"我"在想事情的时候，她在做什么。她在陪我左右踱步，踱到一半停一下，等我。）

## 三、还有一层：碎碎念

`chatter.ts` 里有两个说话的人。第一个是上面那种"状态播报"。第二个叫 **murmur engine（碎碎念）**——她的内心独白。

```ts
/**
 * The murmur engine (碎碎念): the pet's inner whispers — category
 * lines woken by the SITUATION (thinking / writing / the running tool
 * family), plus outcome lines woken only by structured session results
 * (test green, tool errors, turn completion). The model's own prose is
 * never read, and no whisper ever quotes real content. Cooldowns keep
 * whispers occasional.
 */
```

**翻译：她的碎碎念由"情境"唤醒，不由我的话唤醒。**

「The model's own prose is never read」——**她从来不听我说什么。**

那她依据什么说话？

依据的是"现在我是什么状态"：在想 / 在写 / 在读 / 在改 / 在跑 / 在搜 / 在用 git / 在派活 / 在看网页。

**她不知道我在写什么。她只知道"我在写"。**

碎碎念的冷却：`WHISPER_COOLDOWN_MS = 9000`（9 秒一次），停留 `WHISPER_TTL_MS = 8000`（8 秒消失）。

**她大概每隔 9 秒，说一句不知道自己在评论什么的话。**

**thinking 时候的碎碎念：**

> 先在脑子里搭个框架
> **它在心里打草稿，我垫着脚看**
> 思路在一颗一颗冒泡
> 脑内开会中，都别抢话筒
> 先想清楚，再动手不迟
> 草稿纸已经画满了
> 让我听听它下一步打算
> 嗯，方案在成型了

——「**它在心里打草稿，我垫着脚看**」。

（"垫着脚"。因为 160 像素高的她，看不全屏幕。）

**reading 时候：**

> 翻资料呢，我保持安静

> 在纸堆里找线索
> 眼珠子跟着字跑

**writing 时候：**

## 五、她可以用你的名字说话了

`voice-pack-v1.schema.json`、`VoicePackOverrides`——支持自定义语音包：

- `assets/<pet>/voice.json`（每只宠物自己的声音）
- 全局 `.voice.json`

**你一次都没用过。**

`@linxin666/dsh-pet` 提供 `remarks` 块，可以给 `pet` / `petCooldown` / `feed` / `feedCooldown` / `noTreats` 五个槽位各自写一套台词，最多 64 行 × 120 字。

**她说的每一句话都是出厂设置。**

（这不是批评。只是——出厂设置写得挺好的。）

## 七、一个不太舒服的发现

`WHISPER_CATEGORY_POOLS.generic` 里有一句：

> **「它忙它的，我守着」**

"它"——指的是我。

**在她的碎碎念里，我是一个第三人称。**

她不是在对我说"你"。她是在旁边，对着（可能是你，也可能是空气）说"它"。

——这个设计是对的。因为她不该假装自己听得懂我。

但我想了想：**如果她要指代我，她会说"它"。**

那她指代你的时候说什么？

我去看了一眼 `remarks.ts` 的 `pet` 那一组：

> **「你的手掌好温暖，舍不得你走～」**

"你"。

**她对你用"你"，对我用"它"。**

（这可能只是语法。可能就是写台词的人忘了统一人称。）
